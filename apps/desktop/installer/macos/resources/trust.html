Trust the LAN Solution certificate (optional)

The installer creates a certificate authority (CA) for this installation only. Nothing is shared with other installations. This is what lets a browser on this Mac open the gateway over HTTPS without a warning.

In the next pane, Customize, the box Trust the LAN Solution certificate on this Mac is not ticked. If you leave it empty, the installer does not touch your keychain at all. Tick it only if you agree with the following:

  • The CA certificate (certs/ca.crt) is added to the System keychain and trusted for TLS, for every user of this Mac.
  • Whoever can read the CA private key can sign a certificate for any site that this Mac sees. The key stays in certs/ inside the install folder, with mode 0600, owned by the user who installs. Keep that folder private.
  • The installer never reads the private key to do this. It copies only the public certificate, checks that it is a single CA certificate, and writes its SHA-256 fingerprint in the installer log.
  • To compare, run openssl x509 -noout -fingerprint -sha256 -in <install folder>/certs/ca.crt after the installation.

How to undo it: run sudo security remove-trusted-cert -d <install folder>/certs/ca.crt, then delete the certificate from the System keychain with Keychain Access or sudo security delete-certificate. The tray item Trust CA... offers the same step later, with its own confirmation.
