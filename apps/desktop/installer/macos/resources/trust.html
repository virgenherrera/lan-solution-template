Trust the LAN Solution certificate (optional)

The installer creates a certificate authority (CA) for this installation only. Nothing is shared with other installations. This is what lets a browser on this Mac open the gateway over HTTPS without a warning.

In the next pane, Customize, the box Trust the LAN Solution certificate on this Mac is not ticked. If you leave it empty, the installer does not touch your keychain at all. Tick it only if you agree with the following:

  • The CA certificate (certs/ca.crt) is added to the System keychain and trusted for TLS (policy ssl) and for basic X.509 (policy basic), for every user of this Mac.
  • This CA was generated for this installation. The installer records its SHA-256 fingerprint in a file that only an administrator can change, and trusts only a certificate with that fingerprint.
  • Whoever can read the CA private key can sign a certificate for any site that this Mac sees. The key stays in <install folder>/certs/ca.key, with mode 0600, owned by the user who installs. Keep that folder private.
  • The installer never reads the private key to do this. It copies only the public certificate, checks that it is a single CA certificate with the recorded fingerprint, and writes that fingerprint in the installer log.
  • To compare, run openssl x509 -noout -fingerprint -sha256 -in <install folder>/certs/ca.crt after the installation.
  • Removing the application does not undo this trust. The trust stays in the System keychain until you remove it by hand.

How to undo it by hand:

sudo security remove-trusted-cert -d <install folder>/certs/ca.crt
sudo security delete-certificate -c "<name of the CA>" /Library/Keychains/System.keychain

The name of the CA is the CN printed by openssl x509 -noout -subject -in <install folder>/certs/ca.crt. The tray item Trust CA... offers the same step later, with its own confirmation.
