LAN Solution Desktop

This assistant installs the LAN Solution in server mode: the desktop host and its sidecar runtime.

Choose the install location in the next steps. That folder is the base directory: the host, the sidecar, config/, data/ and logs/ live there.

  • Your config/config.json is created once from a template and is never overwritten by a reinstall.
  • Your database belongs to you. Uninstalling never deletes it.
  • No application bundle is installed and nothing outside the chosen folder is written, apart from the receipts macOS keeps for every installer.
