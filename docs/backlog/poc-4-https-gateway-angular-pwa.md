## Goal

[Back to navigation](#navigation)

Source: [PROPOSAL pitch](../roadmap/PROPOSAL.md#poc-4-https-gateway-serving-the-angular-pwa) and [ADR-008](../architecture/adr/ADR-008-tls-trust-model.md).

- Serve one Angular build over HTTPS from the SEA, with a TLS identity generated by Node built-ins only.
- Work in dev, in the SEA binary and as a Tauri sidecar. The sidecar is checked by a simulation ([ADR-008](../architecture/adr/ADR-008-tls-trust-model.md#sidecar-simulation)).
- Clients: browsers and the Tauri WebView.
- Plain-HTTP serving is [POC-1d](poc-1d-angular-link.md). In-memory serving is POC-1f.
- The dev loop does not need the SEA.

| No-gos |
|---|
| No shipped `secure:false`. |
| No `rejectUnauthorized=false`. |
| No automatic CA trust on client devices. |
| No private-key distribution. |
| No offline browser sync. |
| No fake Module Federation remotes. |

- [x] **T0 DER and X.509 builder.** Add `der.ts` and `x509.ts`. Acceptance: a probe script builds a CA and a leaf, then `X509Certificate` parses them, `ca` is true, `checkIssued` and `verify` are true, `openssl verify` accepts the chain, and a `node:https` handshake with `ca:` succeeds by name, by IP and by SNI. Without the CA the client fails with `UNABLE_TO_VERIFY_LEAF_SIGNATURE`. With a wrong host it fails with `ERR_TLS_CERT_ALTNAME_INVALID`. The serial has no leading `0x00`. Source: [ADR-008](../architecture/adr/ADR-008-tls-trust-model.md#node-built-ins-only), [REQ-TLS-01](../requirements/06-web-gateway-https-pwa.md) Done in `c889eea`: `feat: generate X.509 certificates with Node built-ins only`.
- [x] **T1 Identity service and config blocks.** Add `tls/identity.ts`, `tls/san.ts`, the strict `net` and `tls` blocks, and update `config.example.json` and the smoke config writer. `hostname` leaves `serverConfigSchema`. Acceptance: a first start creates `<base>/certs/` mode 0700 with `ca.key` and `leaf.key` mode 0600, `ca.crt` and `leaf.crt`. A second start reuses them. A changed `tls.extraNames` reissues the leaf, keeps the CA and logs the mismatch. A config without `net` or `tls` stops the start. Source: [ADR-008](../architecture/adr/ADR-008-tls-trust-model.md#san-set-and-reissue-rule), [REQ-TLS-01](../requirements/06-web-gateway-https-pwa.md), [REQ-TLS-03](../requirements/06-web-gateway-https-pwa.md), [REQ-TLS-04](../requirements/06-web-gateway-https-pwa.md), [AC-04](../requirements/11-nx-quality-testing.md) Done in `58c5c3d`: `feat: create and reuse the TLS identity under the certs directory`.
- [x] **T2 HTTPS listener and redirect.** Edit `main.ts` and `server-config.ts`, add `redirect-listener.ts`. Acceptance: HTTPS answers on `net.httpsPort`. `net.httpPort` answers `308` to the HTTPS URL. A request with a foreign `Host` is redirected to the configured host and never to the foreign one. Source: [REQ-NET-06](../requirements/06-web-gateway-https-pwa.md), [REQ-NET-08](../requirements/06-web-gateway-https-pwa.md), [AC-05](../requirements/11-nx-quality-testing.md) Done in `b2d4d5d`: `feat: serve the gateway over HTTPS with a safe HTTP redirect`.
- [x] **T3 Serving rules.** Edit `web-handler.ts`. Acceptance: `/api/**` never returns `index.html`. A missing `.js` returns 404. Hashed files carry `immutable`. `index.html` and the service worker carry `no-cache`. Source: [REQ-NET-05](../requirements/06-web-gateway-https-pwa.md), [REQ-NET-07](../requirements/06-web-gateway-https-pwa.md), [REQ-PWA-02](../requirements/06-web-gateway-https-pwa.md), [AC-12](../requirements/11-nx-quality-testing.md), [AC-17](../requirements/11-nx-quality-testing.md) Done in `2d930a6`: `feat: apply the serving rules in the web handler`.
- [x] **T4 Angular PWA.** Run `pnpm dlx @angular/cli` `ng add @angular/pwa` in `apps/web-angular`. Configure the app as Angular 22, zoneless, strict TypeScript, Signals and Tailwind. Hand edits only where no CLI exists. Acceptance: the production build emits `manifest.webmanifest`, icons and a service worker. The dev build has no service worker. Source: [REQ-WEB-01](../requirements/08-web-angular.md), [REQ-PWA-01](../requirements/06-web-gateway-https-pwa.md) Done in `965e323`: `feat: make the web app an installable PWA with the Angular CLI`.
- [x] **T5 Dev loop.** Add `proxy.conf.json` without `secure:false`. The dev script sets `NODE_EXTRA_CA_CERTS=<cwd>/certs/ca.crt`. The app calls relative `/api` URLs. Acceptance: a smoke script requests `/api/**` on :4200 and gets the gateway answer from :8443 through the trusted CA. Source: [REQ-DEV-01](../requirements/06-web-gateway-https-pwa.md), [REQ-DEV-02](../requirements/06-web-gateway-https-pwa.md), [REQ-DEV-03](../requirements/06-web-gateway-https-pwa.md), [REQ-DEV-04](../requirements/06-web-gateway-https-pwa.md), [REQ-DEV-05](../requirements/06-web-gateway-https-pwa.md), [REQ-TEST-05](../requirements/11-nx-quality-testing.md), [AC-14](../requirements/11-nx-quality-testing.md) Done in `7e8a3fc`: `feat: add a dev loop that proxies to the HTTPS gateway and ignores runtime state`.
- [x] **T6 SEA and sidecar-simulation smoke.** Edit `tools/scripts/smoke-sea.ts`. Acceptance: `pnpm package` runs the smoke. The smoke starts the SEA binary from another working directory with piped stdio, reads the NDJSON `status` events, then requests the PWA over HTTPS with the generated CA. The page and the 308 redirect answer. Source: [ADR-008](../architecture/adr/ADR-008-tls-trust-model.md#sidecar-simulation), [REQ-NET-03](../requirements/06-web-gateway-https-pwa.md), [REQ-NET-04](../requirements/06-web-gateway-https-pwa.md), [REQ-SEA-04](../requirements/10-node-sea-distribution.md), [AC-16](../requirements/11-nx-quality-testing.md) Done in `b2d0ff1`: `feat: run the real-binary smoke over HTTPS and add the sidecar simulation`.

Acceptance: every command in [Checks](../standards/README.md#checks) exits 0. `pnpm build`, lint, `test:static` and `pnpm package` pass. Docs done: the [device-trust guide](../architecture/device-trust-guide.md), the [POC-4 result](../results/POC-04-Result.md), ADR-008 final. Source: [REQ-TLS-02](../requirements/06-web-gateway-https-pwa.md), [REQ-TLS-04](../requirements/06-web-gateway-https-pwa.md), [REQ-PWA-03](../requirements/06-web-gateway-https-pwa.md), [AC-04](../requirements/11-nx-quality-testing.md)
